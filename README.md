# REFLEXION
Durante la actividad con Git se pudo experimentar los roles de principal y apoyo, comprendiendo la importancia de la colaboración en un proyecto compartido. Como principal, aprendí a organizar el repositorio, revisar los cambios realizados por el apoyo, integrar aportes mediante ramas y resolver posibles conflictos durante la fusión. Como apoyo, practiqué la clonación del repositorio, la creación de cambios, los commits y el envío de actualizaciones al repositorio remoto. Esta experiencia permitió entender que ambos roles requieren comunicación, orden y responsabilidad para evitar errores. Trabajar con Git facilitó el control de versiones y mostró la importancia de mantener un flujo de trabajo organizado en equipo.
